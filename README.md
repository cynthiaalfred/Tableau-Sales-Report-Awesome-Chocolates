# Tableau Sales Report – Awesome Chocolates

This project showcases how Tableau can be used to turn raw sales data into interactive dashboards and meaningful business insights.

The goal was to explore Tableau features while building a simple but complete sales reporting dashboard using the *Awesome Chocolates* dataset.

📊 [Live Dashboard](https://public.tableau.com/app/profile/cynthia.alfred/viz/SalesReportAwesomeChocolates/Dashboard)

---
# What I Learned

- Building dashboards in Tableau
- Turning raw data into visuals
- Creating filters and interactive reports
- Designing simple business KPIs
- Structuring data for storytelling

---

- Tableau Public
